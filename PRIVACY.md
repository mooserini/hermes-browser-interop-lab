# Privacy Policy

**Last updated: 2026-09-12**

Hermes Browser Interop Lab does not collect, store, sell, share, or transmit user data.

The extension does not use analytics, telemetry, advertising, remote services, or network requests. It does not read or return page text, form-field values, URLs, cookies, browsing history, authentication information, or local browser storage.

When explicitly enabled for the current page, one read-only diagnostic tool counts semantic elements such as headings, landmarks, links, buttons, forms, images missing `alt` attributes, and buttons lacking an accessible name. These aggregate counts remain in the page and are returned only to the locally connected Chrome DevTools for Agents client that invokes the tool.

Access is temporary. It begins when the person clicks the extension action and ends when the page navigates or closes, or when the person clicks the action again.

This policy must be revised before any release that changes data access, storage, transmission, permissions, or third-party services.
